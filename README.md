# LibraryProject

A small Java library-tracking exercise built with Maven and JUnit 5.

## Layout

```
library-tracker/
  pom.xml
  src/main/java/com/example/Book.java
  src/main/java/com/example/Library.java
  src/test/java/com/example/LibraryTest.java
```

## Requirements

- JDK 21 or newer
- Maven 3.9+

## Build and test

```bash
cd library-tracker
mvn test
```
